# Essaddik Chaou — Portfolio

Graphic, multimedia and presentation design.

Website: https://sadikw773-creator.github.io/

36 projects and 364 selected images, with searchable categories and project galleries.

## Hosting

This is a static HTML, CSS and JavaScript website. GitHub Pages publishes the `main` branch from the repository root. No build step is needed.

## Updating the portfolio

Project descriptions and gallery images are listed in `projects.js`; images are stored in `assets/projects/`. Update those files and push to `main` to publish changes.

Project imagery, existing brand marks and supplied assets retain their respective ownership. Portfolio descriptions identify the design contribution and project context.
